Fondamentaux : Comment pense l'IA ?

Les IA ne pensent pas, elles calculent. Comprendre ce principe reste la clé pour mieux prompter.

📊 IA Prédictive vs Générative

  • IA traditionnelle : analyse statistique pour prédire ou classer.
  • IA générative : approche probabiliste pour produire du texte, du code ou des images.

🔢 Probabilité du mot suivant

Le modèle génère mot après mot. À chaque étape, il choisit le mot le plus probable dans le contexte donné.

🔎 Pas de base de données interne

Un LLM ne fouille pas une base de faits. Il manipule des relations mathématiques entre tokens. D'où les hallucinations quand le cadre est flou.

Mythes vs Réalité

Déconstruction des croyances qui font perdre du temps.

❌ Le mythe du prompt magique

Tu es le meilleur expert mondial, tu as 20 ans d'expérience...

Le modèle n'a pas d'ego à flatter.

✅ La réalité scientifique

Donner un rôle aide surtout à borner le vocabulaire et le registre.

❌ Le faux code paramétrique

verbosity=low reasoning=max écrit dans le prompt

Dans un chat classique, ce texte n'active pas des options cachées.

✅ La réalité des interfaces

Les vrais paramètres se règlent via API ou interfaces dédiées.

Le Cadre ASPECCT

Une structure de prompt solide pour fiabiliser les résultats.

A · Action

Définir une mission claire et précise.

S · Steps

Décrire les étapes de raisonnement ou d'exécution.

P · Persona

Attribuer un rôle utile et cohérent.

E · Exemples

Fournir des exemples de sortie attendue.

C · Contexte

Préciser le cadre, les enjeux et le public visé.

C · Contraintes

Poser les règles, limites et garde-fous.

T · Template

Imposer le format de sortie attendu.

    Bonnes Pratiques & Astuces

    Quelques techniques simples qui évitent beaucoup de dégâts.

    ⚙️ Le moteur sous le capot

    Les hyperparamètres comme la température ou le top-p sont souvent figés dans les outils métiers. Donc vos mots restent vos vrais curseurs.

    Plus le prompt est précis, structuré et cadré, plus le résultat devient stable.

    ✅ La puissance de l'exemple

    Donne 1 ou 2 exemples de sortie au lieu de décrire vaguement ce que tu attends.

    🗣️ Penser étape par étape

    Pour les tâches complexes, demande un raisonnement structuré avant la réponse finale.

    🧩 Diviser pour mieux régner

    Découpe les tâches complexes en plusieurs requêtes dans la même conversation.

    🛡️ Contrats de vérité

    Impose au modèle de répondre explicitement qu'une information est absente au lieu d'inventer.

    ⚙️

    Maîtriser les Différents Modèles

    Il n'existe pas de prompt universel. Chaque famille de modèles a ses habitudes.
